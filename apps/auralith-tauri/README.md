# Auralith Tauri Preview

Isolated Tauri 2 application. Does not replace the C# / WinUI native app.

- Product: Auralith Tauri Preview
- Identifier: com.auralith.tauri.preview
- Branch: tauri/auralith-reborn

Audio: Demo / Microphone / System (getDisplayMedia from the button click).
Analyzer: port of auralith-tauri-final bands + envelope.
Output: one window, Clean Capture (F11 / ESC). No virtual camera / broadcast window.

```
cd apps/auralith-tauri
npm install
npm run tauri dev
```
